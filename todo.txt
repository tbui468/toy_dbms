LRU
  FunctionPurpose
    lru_init(capacity)Create replacer that tracks at most capacity frames
    lru_free(lru)Free everything
    lru_set_evictable(lru, frame_id, bool)Mark frame pin/unpin (only true frames can be victims)
    lru_evict(lru, &frame_id)Return least-recently-used evictable frame (or false)
    lru_record_access(lru, frame_id, page_id)Move frame to MRU (inserts it if new; starts non-evictable)
    lru_remove(lru, frame_id)Drop frame immediately (no eviction callback)
    lru_size(lru)Number of currently evictable frames
    lru_capacity(lru)Max frames the replacer was created with

  Implementation notes
    Doubly-linked list with dummy head/tail (head→next = MRU, tail→prev = LRU).
    Open-chaining hash table for O(1) frame_id → node lookup.
    Newly recorded frames start non-evictable (mirrors the usual “pin on first access” buffer-pool pattern).
    lru_size() reports only the count of frames that lru_evict can actually choose.
    All public functions tolerate a NULL replacer (safe no-ops).
